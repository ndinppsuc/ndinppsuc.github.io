# ndinppsuc — Academic Homepage

A lightweight, responsive academic homepage in a classic single-column style.

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a **public** repository named exactly `ndinppsuc.github.io` under the `ndinppsuc` account.
2. Upload the contents of this folder to the repository root (`index.html`, `style.css`, `script.js`, and `assets/`).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After deployment, visit `https://ndinppsuc.github.io/`.

## Personalize before publishing
- Replace the `N` avatar in `index.html` with your own photo. For example, add `assets/profile.jpg` and replace the placeholder `<div class="photo">N</div>` with `<img class="photo" src="assets/profile.jpg" alt="Portrait of ndinppsuc">`.
- Replace `[Paper title to be added]` and `Author list to be added` with the exact ChinaMM 2026 paper metadata.
- Add your public contact email if you want it displayed.
- Add verified paper, project, and code links as they become available.

## Notes
The current publication entry intentionally avoids inventing a paper title or author list. The homepage uses the GitHub ID as the display name until a preferred English name is supplied.
